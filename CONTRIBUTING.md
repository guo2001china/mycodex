# Contributing

MyCodex is currently distributed as packaged desktop installers. Full application source is not published in this repository yet, but community work still matters.

## Useful Contributions

- Installation reports for macOS Apple Silicon, macOS Intel, and Windows x64.
- Translation fixes for English, Simplified Chinese, Japanese, Korean, German, and French.
- Workflow requests: what you want MyCodex to automate, what input you have, and what output you need.
- Model provider requests for subscription-account, OAuth, or API Key flows.
- Documentation improvements, especially screenshots, release notes, and first-run setup.

## Before Opening an Issue

1. Check the latest release: https://github.com/guo2001china/mycodex/releases/latest
2. Read the current release notes: docs/releases/v0.9.6.md
3. Search existing issues for your platform, provider, or workflow.
4. Remove tokens, API keys, cookies, private files, and private logs before posting.

## Issue Templates

- Installation help: use when download, launch, signing, or startup fails.
- Bug report: use when the app behaves differently from what the UI says.
- Feature request: describe the workflow, not only the feature name.
- Model provider request: tell us which provider and connection style you need.
- Localization feedback: point to the exact wording and suggest a better version.
- Community feedback: tell us what would make MyCodex easier to adopt.

## Pull Requests

Documentation and translation PRs are welcome. Keep PRs focused, check links and image paths, and do not include private data.
