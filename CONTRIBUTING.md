# Contributing

DeepSeek企业桌面版 is currently distributed as packaged desktop installers. Full application source is not published in this repository yet, but community work still matters.

## Useful Contributions

- Installation reports for `DeepSeekDesktop-0.9.68-mac.dmg` on Apple Silicon and Intel Mac.
- Windows archive feedback that clearly states it is the older package.
- Translation fixes for English, Simplified Chinese, Japanese, Korean, German, and French.
- AI skill-order requests: the business task, input material, expected output file, and acceptance criteria.
- Token sharing requests: team size, capacity source, permission boundary, and audit needs. Do not paste secrets.
- Documentation improvements, especially screenshots, release notes, and first-run setup.

## Before Opening an Issue

1. Check the latest release: https://github.com/guo2001china/mycodex/releases/latest
2. Read the current release notes: docs/releases/v0.9.68.md
3. Search existing issues for your platform, provider, Token-sharing setup, or skill-order workflow.
4. Remove tokens, API keys, cookies, private files, and private logs before posting.

## Issue Templates

- Installation help: use when download, launch, signing, or startup fails.
- Bug report: use when the app behaves differently from what the UI says.
- Feature request: describe the workflow, not only the feature name.
- Model provider or Token sharing request: describe controlled capacity, not plaintext keys.
- Localization feedback: point to the exact wording and suggest a better version.
- Community feedback: tell us what would make DeepSeek企业桌面版 easier to adopt.

## Pull Requests

Documentation and translation PRs are welcome. Keep PRs focused, check links and image paths, and do not include private data.
