# DeepSeek企业桌面版

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

DeepSeek企业桌面版 v0.9.68 ist ein Desktop-Agent-Arbeitsplatz fuer Unternehmen. Der Fokus liegt auf Token-Sharing, AI-Skill-Auftraegen, gemeinsam genutzten Modellkontingenten, Browser-Aufgaben und lieferbaren Dateien.

Token-Sharing bedeutet kontrollierten Modellzugriff mit Quoten und Berechtigungen. Es bedeutet nicht, persoenliche Schluessel im Klartext zu verteilen.
