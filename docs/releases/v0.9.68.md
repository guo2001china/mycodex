## What Changed

- Public brand upgraded to `DeepSeek企业桌面版`.
- Positioning now centers on Token sharing, AI skill orders, team model quota sharing, enterprise AI desktop workbench, and desktop Agent workflows.
- Copy now states the Token-sharing safety boundary: share controlled model invocation capability, quota, and permissions; do not distribute personal keys in plain text.
- GitHub README, multilingual entry points, release index, issue templates, and operations docs now point to v0.9.68.
- Current download links use `DeepSeekDesktop-0.9.68-mac.dmg`, `DeepSeekDesktop-0.9.68-mac.zip`, and `DeepSeekDesktop-0.9.68-win-x64.zip`.
- Windows x64 is available as the current v0.9.68 package.
- Official site copy and SEO contracts have been rewritten to protect the new brand and keep existing URLs indexable.

## Known Limits

- Windows x64 is distributed as a ZIP package from the v0.9.68 GitHub Release.
- Packaged installers are public. Full source is not published in this repository yet.
- Token sharing should be implemented as controlled model access with authorization and quota boundaries, not as plaintext key distribution.
