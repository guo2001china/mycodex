# MyCodex v0.9.7

Release date: 2026-05-23

## What This Release Improves

MyCodex v0.9.7 makes generated work easier to use.

Agent-created screenshots, images, PDFs, Office documents, and other files now become attachments and previewable artifacts instead of unreadable base64 text in the chat. Local-model users also get a direct settings entry for runtime parameters, so model behavior can be tuned without editing Hermes configuration by hand.

## User Value

- Generated files are easier to inspect, download, and reuse because they stay as attachments and artifact cards.
- Chat stays readable because binary payloads are removed from visible messages and transcripts.
- Local-model users can tune context length, GPU layers, flash attention, batch sizes, RoPE/YARN, and extra launch arguments from the app.
- Model setup is easier to debug because subscription-account and local-model loading errors are surfaced in settings.
- macOS Apple Silicon and Intel installers are refreshed, release validation is complete, and desktop update metadata is published.

## Good For

- Users who ask the Agent to create screenshots, documents, reports, PDFs, images, or other files.
- Local-model users who need more control over `llama-server` runtime behavior.
- Teams that want cleaner conversations where results remain readable and files remain easy to preview.

## Known Limits

- Windows x64 still uses the v0.9.0 archive package until the Windows runtime build is refreshed.
- Full source is not published in this repository yet; packaged installers are released first.
