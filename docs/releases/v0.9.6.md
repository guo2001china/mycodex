# MyCodex v0.9.6

Release date: 2026-05-22

## What This Release Improves

MyCodex v0.9.6 makes the desktop app easier to return to.

When users close the main window, come back from login, open a MyCodex link, or launch the app again, the app now restores the right window instead of leaving users wondering where it went.

## User Value

- You can close and reopen MyCodex with less risk of losing the visible workspace.
- Login callbacks and external links bring you back to the app more reliably.
- Minimized windows are restored before focus, so the app is easier to find.
- The 0.9.6 macOS installers are refreshed and publicly downloadable.

## Good For

- Users who leave MyCodex running while switching between browser, chat, files, and WeChat.
- Users who rely on login callbacks or external links to return to the desktop app.
- Teams that want a steadier packaged desktop build before using MyCodex in regular workflows.
