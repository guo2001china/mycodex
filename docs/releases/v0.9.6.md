# MyCodex v0.9.6

发布日期：2026-05-22

这一版重点修桌面端的窗口生命周期和唤起稳定性。用户关闭主窗口、从登录回调返回、通过外部链接唤起、或者第二次打开 MyCodex 时，客户端现在会更可靠地找到仍然存活的窗口；如果旧窗口已经失效，就不会继续往销毁对象上发事件。

## 用户可感知更新

- 主窗口关闭后，客户端不再继续把登录回调、更新状态或聚焦动作发给已经失效的窗口。
- 从外部链接、登录回调或第二次打开应用唤起 MyCodex 时，会优先恢复并聚焦仍然存活的窗口。
- 如果旧窗口已经关闭，应用会在 ready 后重新创建窗口。
- 最小化窗口被唤起时会先恢复再聚焦，减少“应用已启动但看不到窗口”的情况。
- GitHub README、下载说明和 Release 页面已同步到 0.9.6。

## 桌面窗口和唤起稳定性

- 新增可测试的窗口状态引用，集中跟踪当前主窗口。
- 主窗口 `closed` 后会清空旧引用；如果新窗口已经替换旧窗口，旧窗口关闭不会误清空新窗口。
- live window 入口会过滤已经销毁的窗口，避免 Electron API 在销毁对象上继续发送事件或弹窗。
- 登录回调、关闭保护弹窗、更新状态推送和第二实例唤起都改为通过 live window 入口访问主窗口。
