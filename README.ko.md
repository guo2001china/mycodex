DeepSeek企业桌面版 v0.9.68은 기업용 데스크톱 Agent 작업대입니다. 핵심 용도는 Token공유, AI 스킬 의뢰, 팀 모델 한도 공유, 브라우저 작업, 파일 산출물 생성입니다.

Token공유는 제어된 모델 호출 권한과 한도를 공유하는 것입니다. 개인 키를 평문으로 배포하는 방식은 권장하지 않습니다.
